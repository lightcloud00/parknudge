ParkNudge support

The beta is still in development. These answers reflect the current MVP design.

Location is wrong or unavailable

Search for a garage, address, or landmark, or tap the map where your car is parked. Manual pin correction is free and works when location permission is denied.

I did not receive a meter alert

Confirm ParkNudge notifications are allowed in iPhone Settings and check Focus settings. Alerts whose fire times have already passed are intentionally skipped. Your parking session remains saved even if scheduling fails.

Restore Lifetime Pro

Open Settings in ParkNudge and tap Restore Purchases. Use the same Apple ID that completed the original purchase. The app grants Pro only after StoreKit returns a verified current entitlement.

Delete data

Swipe a completed history item to delete it individually, or use Delete All Parking Data in Settings. Associated local photos and notification requests are removed too.

Report a beta problem

Use GitHub Issues. Never post private coordinates, exported history, receipts, or Apple ID details in a public issue.
