# ParkNudge search-engine handoff

This is the product-owned contract for the shared cross-portfolio search-growth system. **Google Engine**, **Bing Engine**, **Search Engine**, **SEO Engine**, **AEO Engine**, and **ASO Engine** are aliases for that one system. Google Search Console and Bing Webmaster Tools are provider inputs; neither is a separate product or evidence that a URL is indexed.

The machine-readable companion is [`SEARCH-ENGINE.json`](SEARCH-ENGINE.json). ParkNudge issue [#25](https://github.com/lightcloud00/parknudge/issues/25) owns the product lane. The private runtime is owned by [search-growth-engine#1](https://github.com/lightcloud00/search-growth-engine/issues/1), with the ParkNudge registry intake in [search-growth-engine#10](https://github.com/lightcloud00/search-growth-engine/issues/10). [gusdigitalsolutions#103](https://github.com/lightcloud00/gusdigitalsolutions/issues/103) remains the legacy cross-portfolio rollout umbrella.

## Canonical contract

| Field | Current value |
|---|---|
| Product | ParkNudge |
| Repository | `lightcloud00/parknudge` |
| Website source in this repository | `site/` (a source copy; it does not serve the public pages) |
| Public pages | `https://gusdigitalsolutions.com/parknudge/` and its subpages, built from `lightcloud00/gusdigitalsolutions` (`src/pages/parknudge/`) |
| Hosting | The publisher's Cloudflare Pages project `gusdigitalsolutions` |
| Domain state | ParkNudge has no domain of its own |
| Canonical base | `https://gusdigitalsolutions.com/parknudge/` |
| Sitemap | `https://gusdigitalsolutions.com/sitemap-index.xml` (generated by the publisher site) |
| Robots | `https://gusdigitalsolutions.com/robots.txt` |
| LLM facts | `https://gusdigitalsolutions.com/llms.txt` (publisher file that lists ParkNudge); `site/llms.txt` is the source copy |
| IndexNow key | The publisher host's root key file named in `SEARCH-ENGINE.json` |
| Temporary support | Public GitHub Issues with a warning not to post sensitive location data |

Every canonical, Open Graph URL, sitemap entry, and `llms.txt` page link in `site/` is a `https://gusdigitalsolutions.com/parknudge/` URL, and the guide pages' Article and breadcrumb JSON-LD use those URLs too. The home page's Organization and WebSite JSON-LD name the publisher, `https://gusdigitalsolutions.com/`. `python3 site/scripts/check_site.py` checks that:

- each page's canonical is that page's own `https://gusdigitalsolutions.com/parknudge/` URL, and `og:url` equals it;
- each Article's `mainEntityOfPage` and each breadcrumb list's last item equal the page's canonical;
- `sitemap.xml` lists exactly the canonicals, and `llms.txt` lists every one of them;
- every `https://gusdigitalsolutions.com/parknudge/` URL in a published file (everything in `site/` except `site/scripts/`, plus `SEARCH-ENGINE.json`) matches a page or asset in `site/`;
- every absolute URL in a published file uses `gusdigitalsolutions.com`, `github.com`, `apps.apple.com`, `schema.org`, or `www.sitemaps.org`;
- no published file names a `parknudge.<tld>` domain such as `parknudge.app` or `www.parknudge.com`, with or without a scheme.

Search-provider verification, submission, and indexing for those pages remain unproven until [#11](https://github.com/lightcloud00/parknudge/issues/11) and [#25](https://github.com/lightcloud00/parknudge/issues/25) record them.

## Evidence ladder

1. **Source-ready:** static checks pass for metadata, structured data, canonical/sitemap parity, crawler files, Cloudflare assets, and the handoff manifest.
2. **Merged:** the accepted pull request is merged and remote `main` resolves to the recorded commit and tree.
3. **Deployed:** gusdigitalsolutions.com serves the ParkNudge pages with working HTTPS, redirects, navigation, and a real 404 response.
4. **Provider-verified:** gusdigitalsolutions.com is read back as a verified property in Google Search Console and Bing Webmaster Tools.
5. **Submitted:** sitemap and IndexNow requests have timestamped provider receipts. Submission is not indexing proof.
6. **Observed:** provider reports show indexed pages, impressions, queries, clicks, and positions for explicit date ranges. Missing data is unknown, not zero.
7. **Business outcome:** App Store acquisition and verified StoreKit/App Store proceeds—not search configuration—prove installs or revenue.

## Launch procedure

1. Finalize a privacy-safe support channel in #10. ParkNudge has no domain of its own, so there is no domain to buy or configure.
2. Keep this contract and every canonical in `site/` on `https://gusdigitalsolutions.com/parknudge/`. Run `python3 site/scripts/check_site.py` after any change.
3. The public pages are built and deployed from `lightcloud00/gusdigitalsolutions` under that repository's own rules; this repository does not deploy them.
4. Read back HTTPS, status codes, canonical tags, `robots.txt`, `sitemap-index.xml`, `llms.txt`, JSON-LD, the IndexNow key, mobile/desktop layout, console, and navigation for the ParkNudge pages from the public edge.
5. Confirm the ParkNudge pages under the gusdigitalsolutions.com property in Google Search Console and Bing Webmaster Tools. Submit the sitemap to both. Submit only public HTTP 200 changed URLs through IndexNow.
6. Record provider, property/site identity, timestamp, request digest, response, screenshot/export path, deployed commit, and caveats without recording credentials.
7. Establish the aggregate baseline in #14, then use verified query clusters to drive one bounded content experiment at a time in #23.

## Stop gates

This source contract does not purchase a domain, mutate DNS or Cloudflare, deploy a site, verify a provider property, submit URLs, enable paid tools, buy traffic, or release the iOS app. Those actions require their issue-specific authority and public/provider readback.
