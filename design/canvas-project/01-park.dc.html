Exactly one active session

The map is a stand-in

The countdown is derived

Remaining time is computed from an absolute expiry date, so backgrounding, a timezone change or a reboot cannot strand a stale number here.

Garage details outrank coordinates

Floor, section and the note sit above GPS accuracy. Indoors, what finds the car is “Floor 3, Section B” and not eight metres.

One filled button only

Nothing here can be gated

No lock appears in the parking loop. If StoreKit fails entirely this screen is unchanged — which is why the free tier can be stated so plainly.
